Tally

—

This is the browser-only build. There is no server and no database. Your entries are held in this browser's storage, on this device, and nowhere else — nothing is uploaded, nothing syncs between your phone and your laptop, and clearing site data for this page deletes them. Export the CSV if you want a copy that outlives the tab; it is the same file the Flask app produces, and it still imports straight into the wallet app. The arithmetic is not re-done by eye: money.js is a port of money.py's integer cents, and tools/build_static.py runs both against each other and refuses to publish this page if they disagree about a single amount, a single total or a single error message.
