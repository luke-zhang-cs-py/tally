# DESIGN.md

These rules cover every page in the portfolio and the eight project repos: the Flask templates, the browser-only builds in
`docs/app/` (plus `docs/camera/` and `docs/capture/`), the write-ups in `docs/index.html`, and the Chess app. Read this
before designing anything, and follow it every time.

The stack is plain HTML, CSS and JavaScript, with Flask for the apps. There is no Tailwind, no shadcn/ui and no build
step, so don't add any of them.

## Direction: Technical

The pages make their case with evidence: test counts, coverage, CI status and working demos. They should read like a
spec sheet, with names and headline numbers in heavy display type and measured facts in mono. Hierarchy comes from
type size, weight and space, not from boxes.

## Type

| Role | Family | Weights | Token |
|---|---|---|---|
| Display | Bricolage Grotesque (variable) | **200 and 800 only** | `--font-display` |
| Body | IBM Plex Sans | 400, 600 | `--font-sans` |
| Mono | IBM Plex Mono | 400, 600 | `--font-mono` |

```css
--font-display:"Bricolage Grotesque",sans-serif;
--font-sans:"IBM Plex Sans",sans-serif;
--font-mono:"IBM Plex Mono",monospace;
```

- The fonts are self-hosted. Copy [design/fonts.css](design/fonts.css) and [design/fonts/](design/fonts/) into each
  repo, with the licence files. Don't use a Google Fonts `<link>` or any other external font request.
- Never use Inter, Roboto, Open Sans, Arial, system-ui, `-apple-system`, Segoe UI or Helvetica, and not as fallbacks
  either. A stack ends at the generic `sans-serif` or `monospace`.
- Scale: each step is **3×** the one below it.

  | Token | Size | Use |
  |---|---|---|
  | `--text-base` | 16px | body copy, controls |
  | `--text-xl` | 48px | section headings (display, 800) |
  | `--text-display` | `clamp(64px, 14vw, 144px)` | the one headline per page (display, 200 or 800) |
  | `--text-sm` | 13px | mono meta only: counts, hashes, ports, labels |

  Contrast comes from weight extremes. Pair a 200 with an 800, and don't use 500 or 700 in display type.
- Numbers that are measured (tests, coverage, ms, ports) go in `--font-mono` with `font-variant-numeric: tabular-nums`.

## Colour

Each repo has **one dominant colour plus one accent**, drawn at random from a pool of soft, muted defaults. The dominant
is low-chroma and tints the background, surfaces, borders and text, so most of every palette is muted. The accent is
the only stronger colour. No purple or indigo anywhere (OKLCH hue 255–330), and no gradients on white.

Pages open dark (`<html class="theme-dark">` in the markup, so no JS is needed) and switch to light with the toggle.

- The full 13-token set for each repo and theme is in [design/palettes.json](design/palettes.json), generated by
  [design/palettes.py](design/palettes.py) with a fixed seed. Change the seed or the pool there and rerun it; don't
  hand-edit hex values.
- The token contract is unchanged: `--color-bg/surface/surface-subtle/border/border-strong/text-primary/text-muted/`
  `text-subtle/accent/accent-hover/accent-subtle/text-on-accent/danger`, in `:where(:root),.theme-dark{}` and
  `.theme-light{}`.
- A repo's extra tokens (status tags, tracks, chart series, board colours) are derived from its own dominant and accent
  and stay muted. Use the dominant's hue for neutrals; status colours keep their meaning (green ok, amber warn, red
  danger) at low chroma.
- **WCAG AA in both themes, no exceptions:** text needs 4.5:1 against every surface it sits on, and borders on
  controls, focus rings and meaningful graphics need 3:1. The generator checks the core set; each repo's theme tests
  check the rest.
- The localStorage key stays `'theme'` on every page. They all share one origin, so one choice carries across the site.

## Space

- An **8px rhythm**. `--space-N` is N × 4px, and only even N are used (`--space-2` = 8px, `--space-4` = 16px,
  `--space-6` = 24px …). Chess keeps N × .25rem so its Text-size setting still scales the layout.
- Space separates groups. A section gets `--space-16` (64px) or more above it before it gets a rule or a box.

## Hierarchy without boxes

- Separate content with space and type first, then a single hairline (`1px solid var(--color-border)`) if needed.
  Don't put a border, background and shadow on every block.
- Radius: 4px at most on controls (buttons, fields, pills), and 0 on layout blocks.
- Shadows: only on things that float above the page (dialogs, menus, toasts), and no faint 0.1-opacity shadow on
  everything.

## Forbidden

- Three rounded cards in a row (or any equal-width rounded-card grid as the main layout).
- Centred-everything heroes. Headlines and copy are left-aligned on a grid.
- 0.1-opacity drop shadows on everything.
- Purple or indigo gradients, and gradients on white.
- "Modern and clean" as a direction, and Lorem ipsum, "Feature one / Feature two" or any other placeholder copy.
  Use the real project names, test counts from each README, and live demo links.
- Banned fonts, even as fallbacks: Inter, Roboto, Open Sans, Arial, system-ui.
